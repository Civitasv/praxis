# Validation

## Baseline

Python 3.10 is the minimum supported Python version. The neutral core uses only the standard library in V1.

GitHub Actions is the CI source of truth for the repository foundation once `.github/workflows/ci.yml` is present.

## Local checks

Feature-01 grows the validation surface incrementally. The target baseline is:

```bash
python -m unittest discover -s tests -v
python -m compileall -q praxis tests
pnpm typecheck
pnpm test:dsh
```

Until a reviewed `pnpm-lock.yaml` is generated by pnpm and committed, CI may install with `pnpm install --no-frozen-lockfile`. Do not fabricate a lockfile by hand.

## Green definition

A failed or unrun check cannot be reported Green. Mark unavailable or unrun validation as Pending and state the limitation. Source review or agent confidence is not a substitute for execution evidence.
